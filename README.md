## Home Lab Environment

- **Host:** Apple Silicon MacBook M2
- **Virtualization:** UTM
- **Windows Server:** Windows Server 2022 (AD DS, DNS, Group Policy and related exercises)
- **Clients:** Windows 10/11 lab environments
- **Linux:** Ubuntu with OpenSSH
- **Network simulation:** Cisco Packet Tracer
- **Cloud / service tools:** Microsoft 365, Microsoft Entra ID, Microsoft Authenticator and ServiceNow lab environments

The environment is used to practice both configuration and troubleshooting: reproducing a problem, collecting evidence, testing a hypothesis, applying a change when appropriate, and verifying the outcome.
